# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Form 3D, please do NOT disclose it via a public GitHub issue.

Instead, please report security concerns by creating a confidential security advisory on GitHub or by contacting the maintainers directly through private channels.

Please provide:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or proof-of-concept code.
- Details regarding your environment (operating system, Python version, compute device).

We will investigate and respond as quickly as possible.
